# db_fut27cards

Daten-Repository für das FUT27 Sammelheft. Es sammelt die Karten-, Versions-,
Spieler-, Länder-, Liga-, Vereins- und Batch-Daten und erzeugt daraus die
statischen JSON-Dateien, die das Frontend verwendet.

Das Repository enthält die strukturierte Datenbasis für das FUT27 Sammelheft.
Es verwaltet Karten-, Spieler-, Versions-, Länder-, Liga-, Vereins- und
Batch-Daten sowie die daraus erzeugten statischen Indizes und API-Dateien.

Das Frontend verwendet diese Daten als zentrale Quelle für die Darstellung und
Verwaltung der FUT27-Sammlung.
